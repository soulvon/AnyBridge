与 Devin / Windsurf 一致的部分

1

双栏工作区

左侧选择可用模型，右侧设置模型呈现和路由参数。

2

目录搜索与供应商筛选

使用已配置供应商模型目录，不重复录入 API Key。

3

自动推荐 + 可覆盖

默认推导协议和能力，复杂配置在编辑页面中调整。

4

列表内继续管理

添加后支持编辑名称、能力、故障转移、启停和删除。

Cursor 必须调整的语义

  • 标题使用“模型列表 / 添加模型”，不使用“模型映射 / 槽位管理”。
  • 不存在 Devin/Windsurf 的固定 IDE 模型槽位，模型 ID 可直接暴露给 Cursor。
  • 保存目标是 proxy-routes.json，再同步给 Rust Cursor Core。
  • 官方模型不进入 AnyBridge 列表，继续由 Cursor 官方服务处理。

避免重复与误导

  • 添加页不填写 Base URL 和 API Key，它们由供应商统一管理。
  • 不把“OpenAI 暴露格式”展示成用户必须理解的字段，Cursor 路由自动固定为兼容格式。
  • 没有真实测试接口前，不显示伪造延迟。
  • 默认不要求逐个编辑显示名，减少批量添加成本。
