调研后的关键结论

  • AnyBridge 已有供应商、API Key 和模型目录，添加时不应再重复录入连接信息。
  • Cursor Core 的模型源就是 proxy-routes.json 中启用且暴露 OpenAI 格式的路由。
  • 添加模型后若 Core 正在运行，应自动调用 cursor_sync_routes，无需用户再手动同步。
  • Cursor 特有能力是 Agent 工具、Vision、Thinking 和官方账号双轨，而不是“槽位映射”。

首版不建议放进添加页

  • API Key / Base URL：属于供应商配置，避免重复数据源。
  • 复杂 Headers、额外参数、故障转移链：放入添加后的编辑页。
  • 上下文窗口和最大输出：当前代理路由结构不承载，不做假字段。
  • 虚假的延迟测速：没有真实后端接口前不展示随机结果。
