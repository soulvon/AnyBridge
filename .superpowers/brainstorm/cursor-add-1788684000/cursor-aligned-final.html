保持完全一致的产品心智

  • 顶部平台控制台的位置和操作顺序一致。
  • 第二层都是“平台模型列表”工具栏：添加、搜索、计数、批量操作。
  • 列表都展示“显示名、上游目标、能力、启用状态”。
  • 点击添加后都从统一供应商选择模型。
  • 基础配置默认自动完成，高级选项再展开。

仅保留必要的平台差异

  • Devin/Windsurf 叫“模型映射”，Cursor 叫“模型列表”。
  • Devin/Windsurf 左侧是固定 IDE 槽位；Cursor 没有槽位，直接选择供应商模型。
  • Cursor 增加同步状态，因为模型需要推送到 Rust Core。
  • “删除”只移除 Cursor 配置，不删除供应商和共享上游。
  • 官方 Cursor 模型不展示在此表中，继续走官方通道。
