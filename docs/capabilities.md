# AnyBridge 核心能力与权威实现清单 (Authoritative Capabilities)

> **原则**：以下能力在本项目中有且仅有一处权威实现。**严禁另起炉灶或凭空重写更差的备选**；新增需求必须扩展现有模块。

| 业务领域 / 能力 | 权威源文件 / 符号 | 约束与禁止行为 |
|---|---|---|
| **JSONC 解析** | `src-tauri/src/commands/app_localization/lang_pack.rs` (`parse_jsonc`) | 禁裸用 `serde_json::from_str` 解析带注释文件（如 argv.json）；解析失败严禁覆盖原文件。 |
| **文件原子替换与配置存储锁事务** | `src-tauri/src/commands/store_io.rs` (`write_atomic`, `with_file_lock`, `update_provider_store`, `update_proxy_routes`, `update_codex_proxy_routes`；`commands/mod.rs` 再导出 `write_atomic`) | 禁裸用 `fs::write` / `fs::rename` 直接覆盖核心配置或 `app.asar`；必须经规范化路径进程内 `Mutex` + 同目录 `.lock` 文件锁串行化 RMW，并使用 PID+纳秒+原子序号唯一 tmp 重试 rename。 |
| **Windows 无窗子进程** | `src-tauri/src/commands/system/restart.rs` (`HideWindow`) / `cursor_core.rs` (`CREATE_NO_WINDOW`) | GUI 下 spawn 任何命令行工具必须带 `0x0800_0000` 标志（或经 `HideWindow` 抽象），禁弹出黑框。 |
| **进程查询与终止** | `src-tauri/src/commands/platforms/antigravity.rs` (`Toolhelp32` / `kill_antigravity_language_server`) | 严禁使用 PowerShell `Get-CimInstance Win32_Process` 查询进程（卡顿 1-3 秒）；杀进程必须保留路径白名单。 |
| **Workbench 完整性判定** | `src-tauri/src/commands/app_localization/workbench_checks.rs` (`is_valid_workbench`) | 严禁以体积大小（如 >50KB）判定 workbench 损坏；必须以闭合 `</body>` 结构完整性为准。 |
| **内联脚本注入** | `src-tauri/src/commands/app_localization/workbench_checks.rs` (`extract_csp_nonce`) | 原厂 CSP 含 nonce 时注入脚本必须带提取的同名 nonce，否则 `'unsafe-inline'` 被静默忽略。 |
| **BYOK 注入与剥离** | `src-tauri/src/commands/workbench_inject/mod.rs` (`strip_byok_block`) | 还原操作必须是剥离式（只删自己的块），严禁整体备份覆盖（会抹掉汉化块）。 |
| **语言包完整生效链** | `src-tauri/src/commands/app_localization/workbench_checks.rs` (`lang_pack_installed`) | 判定生效必须同时满足四条件：目录存在 + 未被 `.obsolete` 标记 + `languagepacks.json` 注册 + `argv.json` 指向。 |
| **内置模型暴露查找** | `sidecar/lib/local-proxy/routes.js` (`buildExposedIdLookup`) | 两段式构建：字面 ID 优先，渲染别名冲突让位并告警；严禁单条别名冲突抛错毒化全局。 |
| **Gemini 工具调用签名缓存** | `sidecar/lib/gemini-thought-signature.js` (`createGeminiPartCallTracker` / `lookupGeminiToolCall`) | 流式 SSE (`createChatSSEFromGemini`) 与非流式 (`extractToolCalls`) 共用同一提取与缓存链路；命中时精确回放原厂 `thoughtSignature` 与上游 `call.id`，未命中时兜底 `skip_thought_signature_validator` 且不伪造 `id` 给 Vertex v1。 |
| **Google AI Studio / Vertex AI 协议与鉴权** | `src-tauri/src/commands/google_gemini/` (`mod.rs`, `auth.rs`) + `sidecar/lib/google-gemini.js`（+ `google-gemini/thinking.js`） | 唯一端点规范化、协议推断、区域主机校验、`AQ.` Express 识别、OAuth2/SA/ADC/Impersonation Bearer 鉴权、`thinkingLevel`/`thinkingBudget` 归一化及 `build_gemini_model_list_paths` + `host_scheme_and_origin` 模型列表 URL 解析来源；严禁在 config/eval/platforms/proxy 各自手写分散判定或重复拼接 host 内嵌路径。 |
| **Gemini 同源请求无损透传** | `sidecar/lib/local-proxy/upstream-payload.js` (`buildGeminiNativePassthroughPayload`) + `sidecar/local-proxy.js` (`executeGeminiCountTokens`) | `gemini -> gemini`（含 Antigravity `streamGenerateContent` / `generateContent` / `countTokens`）直接原样透传原生负载，剥离 Antigravity/LS 私有包装字段并统一 camelCase，保留 `fileData`、`executableCode`、`codeExecutionResult`、多 part `systemInstruction`、`googleSearch` 原生 `tools` 及 `generationConfig`，禁走有损 IR 拍扁重拼。 |
| **关联主供应商实时解析（全平台 SSOT）** | `src-tauri/src/commands/config/conversions.rs` (`resolve_provider` / `validate_active_source`) + `sidecar/config-cache.js` (`mergeSourceProviderEntry`) + `ui/assets/scripts/state/provider-store.js` (`resolveBoundProviderView`) | 全 6 平台配置（Antigravity / Codex / Claude Code / OpenCode / Grok / Claude Desktop）绑定 `sourceProviderId` 时实时从主供应商解析 `apiHost`/`apiPath`/`apiKey`/`apiKeys`/`enabled` 与 `apiFormat`；禁止优先采信旧静态快照或 `settingsConfig` 残留，源缺失或禁用时显式阻断而不静默回退。 |
| **Responses 假流式输出** | `sidecar/lib/local-proxy/response-emitters.js` (`sendOpenAIResponses`) | `output` 项必须按顺序发 `response.output_item.added/done`，`output_index` 从 1 起，禁漏工具事件。 |
| **上游连接池、系统代理探测与传输韧性** | `sidecar/system-proxy.js` (`SHARED_HTTPS_AGENT` / `SHARED_HTTP_AGENT` / `probeProxyHealth` / `httpsAgentFor`) + `sidecar/lib/http-retry.js` + `sidecar/lib/attempt-runner.js` (`createTargetAttemptRunner` / `resolveCandidateKeys`) + `sidecar/lib/upstream-watchdog.js` + `sidecar/lib/local-proxy/transport.js` | 统一复用共享 HTTP/HTTPS 长连接池；系统代理死端口按周期 TCP 探测降级直连；`local-proxy.js` 与 `handlers/chat.js` 共用 `attempt-runner.js` 候选密钥顺延与 `Retry-After` 微退避调度，禁在各业务模块私造独立 `https.Agent` 或重复外层重试循环。 |
| **标准 SSE 流式解析器** | `sidecar/lib/sse-parser.js` (`createSSEParser` / `parseSSEStream` / `parseSSEText`) | 全 Sidecar 唯一增量 SSE 解析器（基于 `StringDecoder('utf8')` 防止多字节截断乱码，支持无空格 `data:{...}`、多行 `data:`、默认事件与流尾 `flush()`）；禁在业务处理器手写字符串切行解析。 |
| **多协议编解码注册表与流生命周期管线** | `sidecar/lib/codec-registry.js` (`createProtocolStreamTransform` / `runStreamPipeline` / `settleStreamTrackerSuccess` / `settleStreamTrackerFail`) + `sidecar/lib/upstream-decoder.js` + `sidecar/lib/local-proxy/tool-name-codec.js` (`buildCrossProtocolToolNameCodec`) | 统一 4 类上游协议（OpenAI Chat / Responses / Anthropic / Gemini）到 5 类下游目标的真流式编解码，含跨协议非法工具名（`:` / `.`）双向无损安全映射；强制绑定 `res.once('close')` 中止上游、`try/finally` 释放 `providerInflightGate` 槽位，并在流真终结时结算真实 usage 账本。 |
| **前端集中式供应商状态与事务中心** | `ui/assets/scripts/state/provider-store.js` (`persistProviders` / `mutateProviderStore` / `resolveBoundProviderView` / `buildPersistableProviderStore`) | 前端 `providerStore` 唯一读写与持久化入口：串行队列锁、深拷贝快照、过滤虚拟内置供应商、失败 100% 自动回滚内存状态；禁直接调未注册命令或零散覆写后不回滚。 |
| **前端通用配置编辑器共享层** | `ui/assets/scripts/platforms/shared_config_editor.js` (`loadConfigEditorProviderModels` / `runRaceGuardedModelFetch` / `resolveBoundConnectionForSave` / `commitPlatformConfigMutation`) | Claude Code / Codex / OpenCode / Grok 四大编辑器模型拉取防竞态、勾选列表、主供应商实时保存与回滚重绘唯一共享实现。 |
| **平台元数据唯一注册表** | `src-tauri/src/commands/agent_spec/` (`mod.rs`, `specs.rs`) + `ui/assets/scripts/platforms/core.js` (`platformDef`) | `AGENTS` 表是全端平台 id/名称/厂商/配置路径/`api_format` 的唯一真相源（`antigravity` / `antigravity-ide` 为 `"gemini"`）；前端禁静态重复硬编码 `PLATFORM_DEFS`。 |
| **平台接入与还原对称** | `src-tauri/src/commands/platforms/` (`antigravity.rs` / `claude/` / `codex/` 等) | `apply_x` 与 `restore_x` 的异步化、杀进程实现必须完全成对一致，禁只改一侧。 |
| **Codex 进程与 CDP 目标判定** | `src-tauri/src/commands/codex_desktop/mod.rs`（`PS_CODEX_DESKTOP_PROCESS_FILTER`）+ `sidecar/lib/codex-desktop-cdp.js`（`isCodexDesktopTarget` / `pickPageTarget`） | `codex.exe` 有 CLI / 旧版 Desktop / 新版 Desktop / app-server 四形态，判定必须先排除 CLI 目录，helper 只在 kill 路径算；CDP 注入前必须自证目标是 Codex（`app://-/` 或含 codex），遇到 `vscode-*`/`devtools` 页面一律拒绝，绝不"取第一个 page"。判据由 `scripts/check-codex-detect.mjs` 与 `codex-desktop-cdp.test.js` 执行。 |
| **本地网关服务可用性确保** | `src-tauri/src/commands/proxy/lifecycle.rs`（`ensure_proxy_service_ready` / `proxy_port_listening`） | 所有依赖 sidecar 的链路（Cursor Core 启动、Codex Desktop CDP 注入、watcher 补注入）一律调本函数，禁各自再写「探测 + 启动」。判据以**端口连通性**为准而非 child 句柄（外部启动的 sidecar 句柄会丢，误判会杀掉正在供流的实例）。注入类操作必须**先确认网关可用，再 kill 客户端**（事故：issue #38）。 |
| **配置切换原值记账** | `src-tauri/src/commands/agent_stash.rs`（agent-stash.json） | 记账独立于 providers.json（前端 `save_providers` 整体覆盖会抹掉）；original 只在首次记录（幂等），applied 每次 apply 刷新；解析失败先留底 `.corrupt-<纳秒>` 再报错，绝不当作空账本覆盖。 |
| **JSON/JSONC 保形编辑** | `src-tauri/src/commands/jsonc_edit/mod.rs` | 只动目标键值对文本区间（注释/键序/缩进/CRLF/BOM 全保留），支持标量与 Object/Array 缩进对齐替换；定位失败报错中止，禁静默退回全量重写；`ANYBRIDGE_FORMAT_PRESERVING_JSON` 默认开启（仅显式设为 `0`/`false`/`off`/`no` 关闭）。 |
| **插件发布包获取（含版本占位符）** | `src-tauri/src/commands/plugin_asset.rs` (`ReleaseAssetSpec::asset_name` / `install`) | 唯一权威链路：先解析 release tag，再展开 `{tag}` / `{version}` / `{goos}` / `{goarch}` / `{archive_ext}` 得到资产名，随后复用 `extensions/github_download.rs::resolve_release_asset` + `download_asset_with`（与 CPA 安装同一条镜像测速链路）；插件只在 `deploy.asset` 声明，严禁 adapter 另写 curl 下载。 |
| **配置字段级还原** | `src-tauri/src/commands/field_restore.rs`（JSON 字段 / JSON 数组按 id / TOML 标量）+ `src-tauri/src/commands/platforms/yaml_block.rs` (`restore_yaml_fields_via_stash`，YAML 块级) | **所有平台共用这四套，严禁各平台另写还原逻辑**。`ANYBRIDGE_FIELD_RESTORE` 默认开启（仅显式设为 `0`/`false`/`off`/`no` 时退回旧语义）；按 `serde_json::Value` 语义比较写回原值，被外部改过的字段保留用户改动，还原成功后同步清除 `.byok-bak` 及伴生状态文件；YAML 块级还原对用户动过的块整块跳过；写文件一律走 `write_atomic`（含符号链接保护）。已覆盖：Claude Code / Codex / OpenCode / ZCode / Grok / Antigravity / Antigravity IDE / CodeBuddy / WorkBuddy / Pi / Hermes / DeepSeek Harness（12 个）。 |
| **Buddy 家族平台添加页共享流程** | `ui/assets/scripts/platforms/shared_buddy_add.js` | 唯一收口 CodeBuddy / WorkBuddy / ZCode 添加页的供应商列表渲染、模型加载勾选、搜索过滤与确认保存；严禁在各平台各自复制添加页胶水代码。 |
| **模型上下文预设唯一真相源** | `ui/assets/model-context-presets.json`（Rust 经 `src-tauri/src/commands/platforms/model_context.rs` 编译期 `include_str!` 读取） | 严禁在 `src-tauri/resources/` 下维护第二个冗余预设副本。 |
| **共享静态资源单向幂等同步** | `scripts/build-ui.mjs` (`syncSharedResources`) | 构建 UI 时自动对比字节并单向同步：`sidecar/windsurf-catalog.json` → `src-tauri/resources/sidecar/windsurf-catalog.json`、`sidecar/prompts/system-prompt.md` → `src-tauri/resources/prompts/system-prompt.md`、`ui/assets/icons/<同名图标>` → `docs/assets/icons/<同名图标>`；严禁手动双处维护副本。 |
| **Sidecar 受保护字节码构建扫描** | `scripts/build/build_protected_sidecar.py` (`bytenode_compile`) | 自动扫描 `sidecar/` 根目录 `.js` 与 `handlers/`、`lib/` 子树（排除入口、`*.test.js`、`*-test-helpers.js`）；严禁回退为手写硬编码模块清单。 |
| **Rust 配置沙箱隔离与本地网关密钥生成** | `src-tauri/src/commands/config/mod.rs` (`config_dir` / `BYOK_CONFIG_DIR` / `ensure_local_proxy_key_at` / `ensure_local_proxy_key`) | `config_dir()` 优先尊重非空 `BYOK_CONFIG_DIR`（跳过旧目录迁移，对齐 `sidecar/lib/config-dir.js`）；`LOCAL_PROXY_KEY` 读取与按需生成统一收口到 `ensure_local_proxy_key()`（受 `with_file_lock` + `write_atomic` 保护；无沙箱覆盖的单测禁止写入宿主机真实配置），严禁各调用方因缺少 key 直接失败阻断。 |
