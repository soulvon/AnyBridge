## 设计要点

1. **空态不占位**：节点初始带 `hidden` 属性；CSS 用 `.provider-editor-test-result[hidden]{display:none}` 显式兜住（特异性 0,2,0，高于基础类 0,1,0），即使未来基础类改成 `display:flex` 也不会顶掉 hidden。`display:none` 的子项不参与 flex 布局、不产生 `.model-slots-page` 的 14px gap，头部与工作区间距与改动前完全一致。
2. **两态就绪**：`.is-success` 用 `--success/--success-dim`，`.is-error` 用 `--danger/--danger-dim`，全部是 00-foundation.css 已有的语义 token（浅色 + 3 套深色 scheme 自动适配），未引入新色值。
3. **无逻辑改动**：`testProviderInEditor` / `showProviderEditorTestToast` / `fetchModelsForEditor` 等未动一个字节；节点无内联脚本（CSP 坑点不触及）；T3 只需向 `#providerEditorTestResult` 写内容并切换两态类名。
4. **可访问性**：`role="status" aria-live="polite"`，测试结论写入后屏幕阅读器可播报。
5. **未动文案/尺寸/间距**：新增 CSS 全部只作用于新节点自身，无任何选择器命中既有元素。
