把自己的模型，接进每一款 AI 编程智能体。

AnyBridge 是一款开源、本地运行的 BYOK（自带渠道 / 自带密钥）模型接入工作台。它把你的 API 密钥、模型供应商、本地代理、模型映射与智能体配置切换，集中到一个桌面控制面里 —— 不用手写配置，随时一键还原。

下载安装

下载安装包，双击运行就可以。

不用命令行，不用配开发环境。按系统下载安装包，安装后添加供应商、选择智能体，两步就能用上你自己的模型。

三步开始使用

先把渠道填进去，再选择要接入的 AI 编程智能体，剩下的交给 AnyBridge。

  1. 1去发布页下载最新版安装包。Windows 用户一般选择带 Setup.exe 的文件。
  2. 2打开 AnyBridge，添加 API 密钥、接口地址，在线拉取并勾选模型。
  3. 3在「智能体」页选择 Cursor、Claude Code、Pi、Hermes 等工具，一键切换。
打开下载页

按系统选择文件

发布页提供多个系统的安装包，普通用户优先选择安装器。

Windows优先下载 Setup.exe / .msi
macOS优先下载 .dmg（含 Apple Silicon 与 Intel）
Linux按发行版选择 .AppImage / .deb

安装后打开 AnyBridge，先添加供应商和模型，再到「智能体」页选择你正在用的工具并点击切换；需要代理模式的工具按提示重启一次即可。

三种接入方式

不同智能体，用最适合它的那种方式接入。

不强迫所有工具走同一条路。AnyBridge 按工具特性选择代理接管、配置直写或标准 API 网关。

方式 01

本地代理接管

适合不开放自定义密钥的桌面 IDE，通过本机代理识别并转发会话请求。

  • Cursor / Windsurf / Devin
  • 会话请求转发到你的模型
  • 登录、索引、补全等流量正常放行
方式 02

配置文件直写

适合原生支持自定义 API 的智能体，自动写入正确配置文件，写完即可关闭 AnyBridge。

  • Claude Code / Codex / OpenCode / Grok / ZCode
  • Pi / Hermes / DeepSeek Harness / CodeBuddy / WorkBuddy
  • 写入前自动备份，一键切换或恢复
方式 03

本地 API 网关

把不同上游供应商统一暴露成 OpenAI 兼容接口，任何支持自定义 API 的工具都能接入。

  • /v1/chat/completions
  • Anthropic / OpenAI 格式互转
  • 统一模型 ID 与备用链路
Cursor Windsurf Devin Antigravity Antigravity IDE Codex Claude Code Claude Desktop OpenCode Grok CodeBuddy WorkBuddy ZCode Pi Hermes DeepSeek Harness
按智能体使用

每个智能体适合的接入方式不一样，AnyBridge 会按工具处理。

有的只能通过本机代理接入，有的可以写配置直连，也都可以统一走 AnyBridge 本地网关来获得聚合、备用模型和代理增强。

什么时候选直连

稳定、省心，切换后不依赖 AnyBridge 常驻。

适合本身支持自定义 API 的智能体。AnyBridge 把供应商地址、密钥和模型写进工具配置后，工具直接连上游供应商。链路短，适合固定使用某一个渠道。

什么时候选代理

需要聚合、备用模型、图片降级和统一增强时选它。

请求先到 AnyBridge 本地代理，再转给上游模型。这样可以使用模型聚合、故障切换、代理增强、图片理解降级、统一统计和日志诊断。

本机代理

Cursor

推荐代理
代理配置可还原直连需要重启

Cursor 没有自定义 API 入口，通过本机代理接入最合适。AnyBridge 集中管理代理、证书、模型路由和状态检查。

代理接入

在 Cursor 页面启动代理并写入接入配置，重启 Cursor 后请求进入 AnyBridge。

还原直连

在页面里一键还原直连配置，恢复 Cursor 原始状态。

  • 适合统一走 AnyBridge 本地 API 入口。
  • 代理增强、统计和日志对 Cursor 请求同样可用。
  • 环境体检可检查代理与配置是否写入成功。
适合人群：想让 Cursor 使用 AnyBridge 统一模型入口。
本机代理

Windsurf

推荐代理
会话请求转发模型槽位替换Kite 可搭配

Windsurf 不适合手动填自定义 API。AnyBridge 通过本机代理接管会话请求，并把你配置的模型展示给 Windsurf 使用。

代理接入

在 Windsurf 页面一键接入，按提示安装证书并重启 Windsurf。

  • 固定模型槽位可换成自己的模型。
  • 可配合模型映射、备用模型和代理增强。
  • 登录、索引、补全等非会话流量正常放行。
适合人群：想继续用 Windsurf，但希望模型和密钥由自己控制。
本机代理

Devin

推荐代理
Connect-RPC仅处理会话Kite 可搭配

Devin 的会话请求适合通过本机代理接入。AnyBridge 识别会话调用并转换为你配置的供应商格式。

代理接入

在 Devin 页面点击接入，写入代理设置并启动本机代理，重启 Devin 生效。

  • 可使用自己的 Anthropic、OpenAI 或兼容模型。
  • 代理层支持重试、故障切换和日志统计。
  • 非会话请求不强行接管，降低对原功能的影响。
适合人群：想在 Devin 中使用自己的模型池，同时保留原有体验。

特色功能

不只是转发请求，AnyBridge 解决的是日常真会碰到的卡点。

看图模型不足、模型列表被写死、多个工具重复配置、代理出错难排查，这些都放进了同一个控制台。

模型映射

把写死的模型槽位换成你的模型

把客户端固定的模型槽位（如 Cursor 的 cursor-small）映射到你真正想用的模型，也可以统一对外暴露的模型 ID。

图片理解降级

让"不会看图"的模型也能处理截图

截图先交给视觉备用模型分析，文字描述再交给 DeepSeek、GLM、Qwen 等文本模型继续回答，支持按渠道单独指定。

Codex 增强

解锁 Codex 桌面模型列表

通过 CDP 运行时注入把你配置的模型加入 Codex Desktop 下拉列表，不需要改任何二进制文件。

专属解锁

补齐原厂指纹，畅享中转站专线

自动构造 anthropic-beta 头、Thinking 参数与会话指纹，让任意智能体顺利通过中转站校验，不再被 503 / 400 拒绝。

故障切换

主模型失败自动换路

按备用链路切换，配合重试策略处理临时网络错误、429 限流与供应商不可用，长推理请求还有超时保护。

统一供应商

一次配置，多智能体复用

Anthropic、OpenAI、DeepSeek、智谱、月之暗面或自建接口统一管理，不用每个工具重复填密钥。

本地网关

统一 OpenAI 兼容入口

把 AnyBridge 作为本地接口给更多工具调用，地址就是 http://localhost:7450/v1。

可见诊断

环境体检与能力检测

检测证书、路径、配置、Sidecar、端口与供应商连通性，并验证流式、工具调用与视觉能力，避免隐性失败。

扩展中心

CPA 套件一键部署

内置扩展中心管理 CLIProxyAPI + CPA Manager Plus + 插件商店，安装、启动、更新和日志全部在 UI 里完成。

上下文预设

模型上下文窗口自动推荐

内置主流模型推荐配置，添加模型时自动匹配 maxInputTokens 与 maxOutputTokens，不用手动查文档。

界面汉化

英文智能体一键中文化

内置本地化引擎与在线词库热更新，覆盖高频操作、设置与提示，代码与思考链受保护不被误译。

自定义请求头

适配企业内网与私有鉴权

常见问题

普通用户最关心的几个问题。

Windows 应该下载哪个文件？

一般选择发布页里带 Setup.exe 的安装包（也可选 .msi）。下载后双击运行，按安装向导继续即可，不需要命令行环境。

我的 API 密钥会上传到云端吗？

不会。AnyBridge 是本地运行的开源桥接工具，运行时配置保存在你电脑的应用数据目录里，没有任何远程收集服务。

必须会命令行吗？

不需要。下载安装包后打开桌面端，在界面里添加供应商、选择智能体并点击切换即可。

支持哪些 AI 编程智能体？

目前支持 16 款：Cursor、Windsurf、Devin、Antigravity、Antigravity IDE、Codex、Claude Code、Claude Desktop、OpenCode、Grok、CodeBuddy、WorkBuddy、ZCode、Pi、Hermes、DeepSeek Harness；Cline、Continue、Aider 等可通过本地网关接入。

会影响 IDE 原生代码补全吗？

不会。只有会话请求经过转换，代码补全、索引检索与登录鉴权全部走官方原生链路。

不想用了，怎么恢复官方配置？

在智能体页面点击「恢复原始配置」即可一键还原；关闭软件也会自动复原网络环境，绝不残留。
