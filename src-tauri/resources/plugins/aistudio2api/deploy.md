# Deploy: AIStudio2API

## Strategy: Adapter

### Prerequisites

- 不需要 Go / Node / Docker / git：直接使用上游 CI 预编译的 Go 二进制，Web 控制台已内嵌在二进制里
- 不需要本机装 curl / tar：下载与解压由 AnyBridge 主程序完成
- 需要能访问 GitHub：下载走镜像测速，由 AnyBridge 挑最快且能用的源
- 磁盘至少 200 MB：可执行文件约 87 MB，运行期还会在安装目录写入账户与运行数据

### Steps

#### 1. 获取发布包

由 AnyBridge 主程序完成（与 CPA 安装部署同一条链路）：

- 按 `plugin.json` 的 `deploy.asset.repo` 取最新版本号
- 按当前平台拼产物名 `aistudio2api-{tag}-{goos}-{goarch}.{archive_ext}`，`{tag}` 取自该版本（如 `v0.3.1`），并在该版本的资产列表里精确匹配
- 并发测速所有镜像，按速度逐个尝试，单源失败自动重试与换源
- 下载跟随系统代理；全程流式写盘并上报进度

#### 2. 解压并替换二进制

由 AnyBridge 主程序完成：三平台压缩包都有一层顶层目录，解压时统一剥离一层；
只把 `aistudio2api{ext}` 换到安装目录，`.env`、`auths/`、运行数据一概不动。
覆盖前若旧进程仍占着文件，会等待句柄释放，超时则明确报错而不是假装成功。

#### 3. 生成网关配置

由 adapter.js 写入安装目录的 `.env`：监听地址、预览页地址、API 密钥、自动启动生成服务、账户目录。
只改写这几个托管键，用户在控制台设置页保存的其它配置项与注释原样保留。

#### 4. 启动与健康检查

启动由 AnyBridge 插件管理器自动完成（`plugin_start`），参数为 `-open-ui=false`：
Windows 桌面版只驻托盘不开窗口，Linux/macOS 命令行版不弹浏览器。
**验证**：

- 进程启动成功
- GET `http://127.0.0.1:{config.port}/health` 返回 200（免鉴权，只表示管理进程存活）
- 数据面是否可用要看面板「网关状态」里的生成服务状态，或控制台的「账户」页

## Notes

- 上面除第 4 步外的验证都写在主程序里；adapter 不再自带 shell 命令，安装向导不会执行任何本地构建。
- 安装中途失败时，暂存目录与压缩包会被清理，不会在磁盘上留下半成品；已就位的旧二进制不动。
- 「更新」「切换版本」复用同一份获取逻辑：更新取最新版本，切换版本用指定 tag，两者都由主程序下载后替换二进制。
- 端口默认 2048（上游默认）。上游另有预览页端口，配置为「主端口 + 1」以满足其「两个端口不能相同」的校验；被占用时上游会自行改绑空闲端口。
- API 密钥首次安装由 AnyBridge 生成并写入 `.env` 的 `PROXY_API_KEY`，同时登记为本地供应商。两者始终一致；改动密钥后需要「重新生成配置文件」再重启。
- 账户目录设为 `auths/`（上游默认 `auth`），目的是与 `restore_latest_backup` 的回放目录对齐。**卸载会删除安装目录**，`auths/` 会先备份到 `~/.anybridge/aistudio2api-backup-<时间戳>/`，重装时自动放回；`runtime/` 里的请求记录与日志不备份，会随安装目录一起删除。
- 日常管理（添加 Google 账户、模型目录、请求日志、用量、版本）请使用插件面板的「打开管理控制台」按钮，它会打开上游自带的控制台。
- 上游管理端自带在线更新，与本插件的「更新 / 切换版本」是两条独立路径；用管理端自更新会绕过 AnyBridge 的版本记录，建议统一用插件面板操作。

## Uninstall

卸载前 adapter 自动备份 `auths/`（Google 账户凭证）到用户目录。
其余文件连同安装目录一并删除。
